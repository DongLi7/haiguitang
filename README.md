# 海龟汤 · 在线推理游戏

> 生成式人工智能课程大作业

## 一、项目用途

「海龟汤」是一种文字推理游戏：玩家只能看到一段看似诡异的故事（汤面），
通过向主持人提出一个个「是 / 否」问题，逐步缩小范围，最后自己说出真相（汤底）。

本项目把这种游戏做成了网页，解决三个实际使用中的问题：

1. **没人当主持人** —— 传统海龟汤必须有个人拿着答案回答提问，凑不齐人就玩不了。
   本项目由 AI 扮演主持人，一个人也能玩。
2. **判定不客观** —— 玩家说出汤底后，谁来判他是不是真的答对了？
   本项目由 AI 逐条比对 5 个关键要点，给出等级和逐条复盘。
3. **没网也能玩** —— 不填 API Key 时自动切换为本地关键词匹配，离线可用。

适用用户：喜欢推理和文字游戏的普通用户；找不到人一起玩的人；想练表达和追问的人。

## 二、运行环境

| 项目 | 要求 |
|---|---|
| 浏览器 | Chrome / Edge / Firefox / Safari 近两年版本 |
| 网络 | 离线模式不需要；AI 模式需要能访问 api.deepseek.com |
| 服务器 | 不需要，纯静态页面 |

无需安装 Node.js，无需构建，无第三方依赖。

## 三、安装与启动

方式一：下载 index.html，双击用浏览器打开。

方式二（推荐）：在本目录执行

    python -m http.server 8000

然后浏览器打开 http://localhost:8000

建议用方式二。部分浏览器对 file:// 协议下的跨域请求有限制，AI 模式可能无法使用。

## 四、主要功能

1. 5 道原创海龟汤，难度 ★★☆ 到 ★★★★
2. AI 主持人：提问由大模型回答，只输出「是 / 否 / 是也不是 / 无关」
3. AI 判定 + 复盘：说出汤底后逐条比对要点，给出「解出真相 / 棋差一招 / 初见端倪 / 相差甚远」四档结果，看完汤底后显示逐条命中情况
4. 离线兜底：不填 Key 时用本地问答库匹配，功能可用
5. 题库与进度存档：每题的挑战状态记录在浏览器本地

## 五、API Key 配置说明

本项目不包含任何密钥。AI 模式需要使用者自己填写一个 DeepSeek API Key：

1. 打开页面，点「设置」
2. 接口地址保持 `https://api.deepseek.com`
3. 模型名填 deepseek-flash
4. 填入你自己的 API Key，点「保存」
5. 可点「测试连接」确认是否可用

配置示例（不要照抄，Key 是你自己的）：

    接口地址: `https://api.deepseek.com`
    模型名:   deepseek-flash
    API Key:  sk-********************************

Key 只保存在使用者自己浏览器的 localStorage 里，不会上传到任何服务器。

## 六、注意事项

1. API Key 会以明文存放在浏览器 localStorage 中，请不要在公共电脑上填写。
2. 一局游戏约消耗 30 次请求，按 DeepSeek 定价约 ¥0.01–0.02。
3. 离线模式的判定基于关键词匹配，比较粗糙，仅作为兜底。
4. 题库进度存在浏览器本地，换浏览器或清除缓存后会丢失。
5. 本项目不收集任何用户数据。
